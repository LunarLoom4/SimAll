# API Reference

The C++ API reference is generated by Doxygen from the source tree
and embedded into this site via `mkdoxy` / `breathe`.

Run:

```powershell
doxygen docs/Doxyfile
mkdocs serve -f docs/mkdocs.yml
```

…and browse `http://localhost:8000/api/`.

The XML produced under `build/doxygen/xml/` is also used by CI to
diff API changes between commits.
